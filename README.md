# Code Garden 🌱

Code Garden is a free web development learning app built to help people learn coding through lessons, resources, project walkthroughs, and interactive tools in a simple and organized environment.

The goal of the project is to create an accessible place where beginners can learn web development, keep track of their progress, and explore coding resources from both desktop and mobile devices.

## 🚀 Live App

🔗 https://dman1991g.github.io/code-garden/

Use the app directly in your browser — no installation required.

---

## 📚 What Code Garden Is For

Code Garden was created to help users:

- Learn web development concepts
- Access coding lessons and study resources
- Follow project walkthroughs
- Track learning progress
- Study from mobile or desktop
- Keep coding notes in one place
- Explore coding in a beginner-friendly way

The app is designed to continue growing with more lessons, tools, and learning features over time.

## ✨ Features
